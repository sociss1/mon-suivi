# Mon Suivi

Application de suivi personnel : journée, habitudes, budget en F CFA et projets, avec un coach qui indique ce qui est normal et ce qu'il faut corriger.

- Installable sur l'écran d'accueil (Android et iPhone)
- Fonctionne sans connexion après la première visite
- Les données restent sur l'appareil de chaque personne

Pour publier une mise à jour, remplace les fichiers puis change la valeur de `V` au début de `sw.js`.
